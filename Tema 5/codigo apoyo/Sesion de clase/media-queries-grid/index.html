CSS Grid + Media Queries – Playground

Demostración interactiva de cómo cambia un layout con Grid cuando aplicamos media queries. En el playground simulamos los breakpoints ajustando el ancho del contenedor y cambiando el número de columnas/layout.

1. Grid de tarjetas de producto

Sin media queries el número de columnas es fijo y el grid puede quedar apelotonado en pantallas pequeñas. Con media queries (aquí simuladas), el número de columnas se adapta al ancho disponible.

👉 Cambia de modo y ajusta el ancho del contenedor para ver la diferencia.
Ancho del contenedor: 900px

Modo activo: Sin media queries. Siempre se usan 4 columnas (repeat(4, 1fr)), aunque el contenedor sea muy estrecho.

Modo activo: Con media queries (simuladas). “Móvil”: 2 columnas · “Tablet”: 3 columnas · “Escritorio”: 4 columnas.

/* Forma “real” con media queries en CSS (para explicar en clase) */ .product-grid { display: grid; gap: 0.75rem; } /* Base móvil: 2 columnas */ .product-grid { grid-template-columns: repeat(2, 1fr); } @media (min-width: 640px) { .product-grid { grid-template-columns: repeat(3, 1fr); /* tablet */ } } @media (min-width: 960px) { .product-grid { grid-template-columns: repeat(4, 1fr); /* escritorio */ } } /* En el playground simulamos estos puntos de corte usando data-size="small|medium|large", para que el slider de ancho del contenedor dispare estos cambios en lugar del viewport. */

2. Layout completo: Dashboard

Aquí combinamos Grid con grid-template-areas para construir un dashboard. Sin media queries el layout siempre es de escritorio; con media queries (simuladas), en móvil se apila en una sola columna.

👉 Observa cómo la sidebar pasa a estar debajo del header cuando el contenedor es estrecho.
Ancho del contenedor: 900px

Modo activo: Sin media queries. Siempre 2 columnas (sidebar + contenido), incluso con contenedor estrecho.

Modo activo: Con media queries (simuladas). “Móvil”: todo apilado; “Escritorio”: sidebar a la izquierda y contenido a la derecha.
