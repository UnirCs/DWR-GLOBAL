Comparativa de maquetación: sin Flexbox vs Flexbox

Ejemplo didáctico para mostrar cómo un mismo contenedor se adapta a distintas pantallas con media queries sin Flexbox frente a Flexbox sin media queries.

💡 Prueba a cambiar el tamaño de la ventana del navegador para ver la diferencia.

1. Contenedor SIN Flexbox
(requiere media queries)

Aquí usamos inline-block y @media para pasar de 1 columna (móvil) a 2 (tablet) y 3 (desktop).

Ejemplo sin Flexbox

Elemento 2
Elemento 3
  • Móvil (< 600px): cada tarjeta ocupa el 100% del ancho.
  • Tablet (≥ 600px): las tarjetas pasan a medir el 48% → 2 columnas.
  • Desktop (≥ 900px): las tarjetas pasan a medir el 30% → 3 columnas.
  • Si quitas las @media, el layout deja de adaptarse correctamente.
CSS usado en este ejemplo
.contenedor-no-flex .item {
  display: inline-block;
  width: 100%;
  margin-bottom: 12px;
  background: #e3f0ff;
  padding: 12px;
  border-radius: 8px;
  text-align: center;
  font-weight: 500;
  border: 1px solid rgba(59, 130, 246, 0.25);
}

/* Tablet: dos columnas */
@media (min-width: 600px) {
  .contenedor-no-flex .item {
    width: 48%;
  }
}

/* Desktop: tres columnas */
@media (min-width: 900px) {
  .contenedor-no-flex .item {
    width: 30%;
  }
}

2. Contenedor CON Flexbox
(sin media queries)

Aquí usamos display: flex, flex-wrap y flex: 1 1 250px para que el navegador calcule cuántas tarjetas caben en cada fila sin necesidad de breakpoints.

Elemento 3
  • Cada tarjeta intenta medir 250px de ancho, pero puede encogerse.
  • En pantallas pequeñas, se verán en una columna.
  • A medida que haya más espacio, cabrán 2, 3, etc. por fila, automáticamente.
  • No hay ni una sola @media en estos estilos.
CSS usado en este ejemplo
.contenedor-flex {
  display: flex;
  flex-wrap: wrap;
  gap: 12px;
}

.contenedor-flex .item {
  flex: 1 1 250px; /* intenta 250px, pero se adapta */
  background: #ffe5e5;
  padding: 12px;
  border-radius: 8px;
  text-align: center;
  font-weight: 500;
  border: 1px solid rgba(248, 113, 113, 0.45);
}
