Guía visual: ejemplos básicos de Flexbox

Cada bloque muestra a la izquierda el contenedor con sus ítems, y a la derecha el CSS que lo hace funcionar.

0. Activar Flexbox en un contenedor

Lo imprescindible para usar Flexbox es activar display:flex.

1
2
3
.flex-basic {
    display: flex;
    border: 1px solid #cbd5e1;
    padding: 8px;
    gap: 8px;
    }
    
    .flex-basic .item {
    background: #3b82f6;
    color: white;
    padding: 8px 12px;
    border-radius: 6px;
    }

1. Contenedor usando display: inline-flex

inline-flex funciona igual que flex, pero el contenedor se comporta como un elemento en línea, ocupando solo su contenido.

A
B
C

← El contenedor solo mide lo que ocupan sus ítems.

.inline-flex-demo {
  display: inline-flex;
  gap: 8px;
  padding: 8px 12px;
  background: #fef3c7;
  border: 1px solid #facc15;
  border-radius: 10px;
}

.inline-flex-demo .item {
  background: #f59e0b;
  color: white;
  padding: 8px 12px;
  border-radius: 6px;
