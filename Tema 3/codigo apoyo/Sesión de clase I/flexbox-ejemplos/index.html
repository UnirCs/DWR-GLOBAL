Ejemplos prácticos de Flexbox en interfaces

En esta página se muestran varios patrones habituales de interfaz maquetados con Flexbox: un menú de navegación, un conjunto de tarjetas, un formulario y un layout con sidebar. Cada bloque incluye una breve explicación de cómo se está utilizando Flexbox.

Ejemplo 1

Menú de navegación con Flexbox (el de esta página)

En la cabecera de la página se utiliza un contenedor flex para alinear el logotipo y el menú en una sola fila. El menú en sí también es un contenedor flex para repartir sus elementos de manera uniforme y permitir que se adapten en pantallas pequeñas con flex-wrap.

Propiedades clave:

  • .main-header-inner { display: flex; justify-content: space-between; }
  • .nav { display: flex; gap: 16px; }
  • @media se usa para cambiar a columna en móviles.
.main-header-inner {
  display: flex;
  align-items: center;
  justify-content: space-between;
}

.nav {
  display: flex;
  gap: 16px;
}
Ejemplo 2

Tarjetas de información (cards)

Aquí Flexbox se usa para distribuir tarjetas en una fila que se adapta a distintos anchos de pantalla. El contenedor utiliza flex-wrap para que las tarjetas salten a la siguiente línea cuando no hay espacio suficiente.

Curso
Flexbox desde cero

Aprende los conceptos básicos de contenedores e ítems flexibles, con ejemplos prácticos.

Práctica
Maquetación responsive

Crea layouts que se adapten automáticamente a diferentes tamaños de pantalla con pocas líneas de CSS.

Ejemplo
Componentes reutilizables

Usa Flexbox para que las tarjetas funcionen igual aunque cambie la cantidad de texto o de botones. 

.cards-container {
  display: flex;
  flex-wrap: wrap;
  gap: 14px;
}

.card {
  flex: 1 1 220px;
  display: flex;
  flex-direction: column;
}
Ejemplo 3

Formulario maquetado con Flexbox

En este formulario Flexbox se usa para colocar varios campos en la misma fila. Gracias a flex-wrap, cuando no hay espacio suficiente, los campos pasan automáticamente a la siguiente línea sin necesidad de modificar el HTML. 

.form-row {
  display: flex;
  gap: 10px;
  flex-wrap: wrap;
}

.form-field {
  flex: 1 1 220px;
  display: flex;
  flex-direction: column;
}
Ejemplo 4

Layout con panel lateral y contenido principal

Aquí Flexbox se usa para crear un layout muy típico: un panel lateral con filtros y un área principal de contenido. En pantallas anchas se muestran en dos columnas; en pantallas pequeñas se apilan gracias a flex-wrap.

Filtros

  • 🏷️ Categoría: Todos
  • ⭐ Valoración > 4.0
  • 💶 Precio: < 50€
  • 📍 Distancia < 5 km

Resultados

Esta zona podría contener tarjetas, una tabla de resultados o cualquier otro componente. El contenedor flex reparte el espacio disponible entre el panel lateral y el contenido principal. 

.layout-container {
  display: flex;
  gap: 16px;
  flex-wrap: wrap;
}

.layout-sidebar {
  flex: 0 0 220px;
}

.layout-main {
  flex: 1 1 260px;
}
