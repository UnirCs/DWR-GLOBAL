Cómo se maquetaba antes de Flexbox

1. Alineación usando position

Para colocar un elemento en una esquina o posición concreta del contenedor, se usaba position: absolute. Esto sacaba el elemento del flujo natural, dificultando layouts flexibles.

Elemento
Contenedor 
.position-container {
  position: relative;
  width: 280px;
  height: 180px;
  background: #eef2ff;
  border-radius: 10px;
}

.position-container .item {
  position: absolute;
  top: 12px;
  right: 12px;
  background: #60a5fa;
  padding: 8px 14px;
  border-radius: 6px;
  color: white;
}

2. Alineación usando float

Float se pensó para imágenes, pero se usó durante años para maquetar columnas. Para alinear un elemento a un lado se usaba float, pero rompía el flujo y obligaba a utilizar clear para corregir problemas.

Elemento
Contenedor 
.float-container {
  width: 280px;
  min-height: 180px;
  background: #e0f2fe;
  border-radius: 10px;
  padding: 12px;
}

.float-container .item {
  float: right;
  background: #38bdf8;
  padding: 8px 14px;
  border-radius: 6px;
  color: white;
}

3. Layout con inline-block

Para crear “columnas”, se utilizaba display:inline-block. El problema: aparecían espacios entre elementos, y se eliminaban con el “hack” de poner font-size: 0 en el contenedor.

Elemento
Elemento
Elemento
.inline-container {
  width: 280px;
  background: #fef3c7;
  padding: 12px;
  border-radius: 10px;
  font-size: 0; /* Hack para eliminar espacios */
}

.inline-container .item {
  display: inline-block;
  width: 80px;
  background: #fbbf24;
  padding: 10px 0;
  border-radius: 6px;
  color: white;
  font-size: 14px; /* Se restaura */
  text-align: center;
}
