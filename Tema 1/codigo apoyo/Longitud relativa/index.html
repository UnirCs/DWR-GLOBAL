Unidades de Longitud Relativas en CSS

Las unidades relativas se adaptan al contexto y mejoran la accesibilidad

¿Qué son las unidades relativas?

Las unidades relativas se calculan en relación a otro valor (fuente, viewport, etc.). Son fundamentales para crear diseños responsive y accesibles que se adapten a diferentes tamaños de pantalla y preferencias de usuario.

📝 Unidades Relativas a la Fuente

em - Relativo al tamaño de fuente del elemento padre

Padre con font-size: 20px

1em = 20px
2em = 40px
0.5em = 10px

em es relativo al tamaño de fuente del elemento padre. Si anidas elementos, los valores se multiplican (compounding effect).

.padre { font-size: 20px; }
.hijo { font-size: 2em; } /* 40px */

rem - Relativo al tamaño de fuente del elemento raíz (html)

Elemento raíz (html) con font-size: 16px (por defecto)

1rem = 16px
2rem = 32px
1.5rem = 24px

rem (root em) siempre es relativo al elemento raíz <html>. No sufre el efecto compuesto, lo que lo hace más predecible.

html { font-size: 16px; }
.texto { font-size: 1.5rem; } /* 24px */

🖥️ Unidades Relativas al Viewport

vw - Viewport Width (1% del ancho del viewport)

50vw = 50% del ancho
75vw = 75% del ancho

1vw = 1% del ancho del viewport. Ideal para elementos que deben ocupar un porcentaje específico del ancho de la ventana.

vh - Viewport Height (1% del alto del viewport)

10vh
20vh
15vh

1vh = 1% del alto del viewport. Perfecto para secciones que ocupan toda la altura de la pantalla.

.seccion-completa { min-height: 100vh; } /* Ocupa toda la pantalla */
