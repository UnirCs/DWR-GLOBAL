01 / Concepto

¿Qué es Bootstrap?

Imagina que tienes que construir una casa. Podrías cortar cada tabla y forjar cada clavo, o podrías ir a una ferretería donde ya está todo medido, etiquetado y listo para encajar. Bootstrap es esa ferretería para hacer páginas web.

⌗

Sistema de rejilla potente

Divide la pantalla en 12 columnas para que coloques tu contenido sin pelear con el CSS.

🛠

Utilidades listas

Cientos de clases ya escritas: márgenes, colores, tipografía, sombras… solo las pones en tu HTML.

📱

Compatible en todos lados

Tu web se ve bien en móvil, tablet y ordenador sin que tengas que preocuparte por cada caso.

⚡

Acelera tu desarrollo

En lugar de empezar desde cero, partes con un kit completo: ahorras horas (y dolores de cabeza).

📚

Documentación enorme

Cada componente, ejemplo y variante está documentada con código copiable en su web oficial.

🧩

Componentes plug-and-play

Botones, formularios, alertas, menús, tarjetas… ya hechos. Solo eliges y los usas.

En una frase Bootstrap es un framework de CSS: una librería de estilos y componentes prefabricados que pegas en tu HTML para construir páginas modernas y responsivas mucho más rápido.
02 / Instalación

¿Cómo se instala?

Hay dos caminos. Uno es para empezar en 30 segundos. El otro es para proyectos más serios donde quieres controlar las versiones.

Vía CDN Recomendado para empezar

Pegas dos líneas en tu HTML y listo. Bootstrap se descarga desde su web oficial.

¿Qué es un CDN? Content Delivery Network (red de distribución de contenido). Un conjunto de servidores repartidos por el mundo que sirven archivos —como Bootstrap— desde el más cercano al usuario, para que carguen rápido. En la práctica: enlazas un fichero alojado en otro servidor, sin tener que descargarlo tú. 
<!-- Dentro de <head> -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">

<!-- Antes de cerrar </body> -->
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>

Con gestor de paquetes Profesional

Si usas Node.js, npm o yarn, Bootstrap se instala como una dependencia más.

# Con npm
npm install bootstrap@5.3.3

# Con yarn
yarn add bootstrap@5.3.3
¿Cuál elijo? Si estás aprendiendo o haciendo una página rápida, CDN. Si trabajas en un proyecto con build (React, Vue, Vite…) usa npm.
03 / Rejilla

El sistema de rejilla.

Bootstrap parte el ancho de la pantalla en 12 columnas invisibles. Tu trabajo es decir cuántas columnas ocupa cada bloque de tu contenido. Si todos los bloques de una fila suman 12, ocupan toda la pantalla.

La jerarquía oficial

.container → caja exterior con márgenes laterales
.row → fila horizontal
.col → columna dentro de la fila

Variantes del contenedor:

.container tiene márgenes laterales automáticos.
.container-fluid ocupa el 100% del ancho.

Ejemplo mínimo

<div class="container">
  <div class="row">
    <div class="col-6">Mitad izquierda</div>
    <div class="col-6">Mitad derecha</div>
  </div>
</div>

¿Por qué col-6? Porque 6 + 6 = 12. Cada columna ocupa la mitad.

04 / Responsive

    
Breakpoints: una web, todas las pantallas.

    

      Bootstrap usa el enfoque mobile-first: primero diseñas para móvil,
      luego añades reglas para pantallas más grandes. Cada prefijo (sm,
      md,
      lg…) activa un comportamiento a partir de cierto ancho.
    


    

      
        

          Abreviatura
          Tamaño mínimo
          Dispositivo
          Ejemplo de uso
        

      
      
        
col-0pxExtra pequeñoMóviles muy pequeños

        
col-sm-576pxPequeñoMóviles en horizontal

        
col-md-768pxMedianoTablets

        
col-lg-992pxGrandePortátiles

        
col-xl-1200pxExtra grandeMonitores estándar

        
col-xxl-1400pxMuy grandePantallas amplias

      
    


    

      
¿Cómo se combinan?

      
Puedes apilar varias clases para que un bloque cambie según la pantalla. Mira este caso típico:

      
<div class="col-12 col-md-6 col-lg-4">...</div>

      

        

          📱 En móvil
          
ocupa 12/12 (toda la fila)

        

        

          💻 En tablet
          
ocupa 6/12 (la mitad)

        

        

          🖥 En portátil+
          
ocupa 4/12 (un tercio)

06 / Personalizar

    
¿Y si quiero mi propio estilo?

    

      Bootstrap te da una base, pero no te ata. Puedes añadir tus propias clases
      junto a las suyas para sobreescribir colores, tamaños, bordes… lo que quieras.
    


    

      

        
El truco: clases extra en el HTML

        
Mantienes la clase de Bootstrap y añades una tuya con los cambios.

        
<!-- HTML -->
<button class="btn btn-primary btn-reserva-gimnasio">
  Reservar
</button>

/* Tu CSS */
.btn-reserva-gimnasio {
  background: #ff6b6b;
  border-radius: 999px;
  text-transform: uppercase;
  letter-spacing: 0.1em;
}

      


      

        
Resultado

      Consejo de oro 🪙
      No reescribas Bootstrap entero. Empieza usando las clases tal cual y solo personaliza lo necesario. Tu CSS será más corto y mantenible.

07 / Caso práctico

    
Cómo hacer una página web realista con Bootstrap

    

      Hasta aquí has visto las piezas sueltas. Ahora vamos a montar una página real
      de un gimnasio ficticio (ActivaFit), trozo a trozo. A la izquierda verás el resultado;
      a la derecha, el código exacto que lo produce. Las clases de Bootstrap están resaltadas
      para que veas dónde está la magia.
    


    

      Cómo leer este apartado 📖
      Cada bloque es independiente. Si copias y pegas todos en orden dentro de un HTML con Bootstrap enlazado, obtendrás la web completa que verás abajo del todo.
    


    
    

      

        PASO 1
        
Barra de navegación (navbar)

      

      

        Toda web seria empieza con una barra arriba: logo a la izquierda, enlaces a la derecha.
        Bootstrap nos da el componente navbar con su botón hamburguesa para móvil ya hecho.

              ↑ Componente navbar de Bootstrap. En móvil aparece el botón ☰ solo.
            

          

        


        

          
 Código HTML

          
<nav class="navbar navbar-expand-lg navbar-dark bg-dark">

  <a class="navbar-brand" href="#">
    ActivaFit
  </a>

  <!-- Botón hamburguesa para móvil -->
  <button class="navbar-toggler"
          data-bs-toggle="collapse"
          data-bs-target="#nav1">
    <span class="navbar-toggler-icon"></span>
  </button>

  <div class="collapse navbar-collapse" id="nav1">
    <ul class="navbar-nav">
      <li class="nav-item">
        <a class="nav-link" href="#">Inicio</a>
      </li>
      <li class="nav-item">
        <a class="nav-link" href="#">Clases</a>
      </li>
      <li class="nav-item">
        <a class="nav-link" href="#">Precios</a>
      </li>
      <li class="nav-item">
        <a class="nav-link" href="#">Contacto</a>
      </li>
    </ul>
  </div>

</nav>

        

      


      

        Las clases clave 🔑
        navbar es el componente. navbar-expand-lg hace que sea horizontal en pantallas grandes y se pliegue en móvil. navbar-dark bg-dark le da fondo oscuro. navbar-brand es el logo, nav-link cada enlace. Todo viene de Bootstrap, sin tocar CSS propio.
      

    


    
    

      

        PASO 2
        
Cabecera (hero) con clase propia

      

      

        Para la cabecera Bootstrap no nos da un componente concreto, así que usamos nuestra propia clase
        .gym-hero definida en el CSS. Dentro va un botón de Bootstrap (btn)
        para la llamada a la acción.

 Código HTML + CSS

          
<!-- HTML -->
<section class="gym-hero">

  <h1>Entrena. Suda. Repite.</h1>

  <p>
    El gimnasio donde tu mejor versión
    ya tiene cita.
  </p>

  <a href="#" class="btn btn-light">
    Reserva tu prueba gratis
  </a>

</section>

/* CSS propio */
.gym-hero {
  background: linear-gradient(135deg, #6f3fff, #ff6b6b);
  color: #fff;
  padding: 60px 24px;
  text-align: center;
}
.gym-hero h1 { font-size: 44px; }
.gym-hero p  { font-size: 17px; }

        

      


      

        Las clases clave 🔑
        .gym-hero es nuestra clase: gradiente, padding y centrado. El botón btn btn-light sí viene de Bootstrap. Es el patrón típico: Bootstrap para los componentes que ya existen (botones, navbar, cards…) y CSS propio para lo que es único de tu web.
      

    


    
    

      

        PASO 3
        
Tarjetas de servicios con la rejilla

      

      

        Aquí entra la rejilla de 12 columnas. Queremos 3 tarjetas en pantalla grande
        y 1 en móvil. Solución: col-md-4 (4 de 12 = un tercio en pantallas medianas en adelante,
        ancho completo en móvil).

<!-- HTML -->
<div class="container">
  <h2>Nuestras clases</h2>

  <div class="row">

    <!-- Tarjeta 1 -->
    <div class="col-md-4">
      <div class="gym-card">

  border-radius: 10px;
  background: #fff;

        Las clases clave 🔑
        container centra el contenido. row es la fila. col-md-4 es la magia: en pantallas md en adelante cada tarjeta ocupa 4 columnas (4+4+4 = 12); en móvil, ocupan 12 cada una y se apilan. El botón btn btn-primary es de Bootstrap; el estilo de la tarjeta (.gym-card) lo hacemos nosotros.
      

    


    
    

      

        PASO 4
        
Galería con rejilla mixta (responsive)

      

      

        Galería de instalaciones: 2 columnas en móvil, 4 en escritorio. Esto se hace
        combinando dos breakpoints en la misma columna: col-6 col-md-3. Bootstrap aplica
        el primero por defecto y el segundo a partir de md.
      


      

        

          
 Resultado

          

            

              
Instalaciones

 Código HTML + CSS

          
<!-- HTML -->
<div class="container">
  <h2>Instalaciones</h2>

  <div class="row">

    <!-- En móvil:    2 columnas (col-6)
         En md (≥768): 4 columnas (col-md-3) -->

    <div class="col-6 col-md-3">
      <div class="gym-thumb gym-thumb-1">
        SALA 1
      </div>
    </div>

    <div class="col-6 col-md-3">
      <div class="gym-thumb gym-thumb-2">
        CARDIO
      </div>
    </div>

    <!-- ...y PESAS, SAUNA igual -->

  </div>
</div>

/* CSS propio */
.gym-thumb {
  aspect-ratio: 1 / 1;
  border-radius: 8px;
  display: flex;
  align-items: center;
  justify-content: center;
  color: #fff;
  font-weight: 700;
}
.gym-thumb-1 { background: linear-gradient(135deg, #ff6b6b, #ffd166); }
.gym-thumb-2 { background: linear-gradient(135deg, #6f3fff, #06d6a0); }

        

      


      

        Las clases clave 🔑
        col-6 col-md-3 dice: "en móvil, 2 por fila (6+6=12); a partir de md, 4 por fila (3+3+3+3=12)". Es la forma estándar de Bootstrap para hacer una rejilla que cambia según el tamaño de pantalla, sin escribir ni una media query.
      

    


    
    

      

        PASO 5
        
Pie de página (footer)

      

      

        Cerramos con un footer de dos columnas: a la izquierda la dirección, a la derecha las redes.
        Usamos col-md-6 para partir el ancho en dos y nuestra clase .gym-footer
        para el estilo oscuro.

        Otra vez el patrón container → row → col-md-6 + col-md-6 = dos columnas iguales en escritorio que se apilan en móvil automáticamente. El resto (colores, espaciados) va en .gym-footer, que es nuestra clase.
      

    


    
    

      

        RESULTADO
        
Todo junto: la web completa de ActivaFit

      

      

        Al juntar los 5 pasos, esto es lo que obtienes. Una página real, responsive, usando solo
        componentes de Bootstrap (navbar, btn) y
        la rejilla (container, row, col-*),
        más un puñado de clases propias para el estilo.
      


      

        
▾ Vista previa completa (interactiva)

        
      


      

        Lo que has aprendido en este apartado 🎓
        Una web realista es la suma de bloques estándar: navbar + hero + cards + galería + footer. De Bootstrap usamos solo componentes (navbar, btn) y la rejilla (container, row, col-*). El estilo lo metemos en clases propias (.gym-hero, .gym-card, .gym-thumb, .gym-footer). Así el HTML queda limpio y el CSS centralizado, en vez de llenar las etiquetas de utility classes.
