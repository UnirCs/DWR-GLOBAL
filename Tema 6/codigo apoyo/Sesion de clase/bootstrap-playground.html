01 / Concepto

¿Qué es Bootstrap?

Imagina que tienes que construir una casa. Podrías cortar cada tabla y forjar cada clavo, o podrías ir a una ferretería donde ya está todo medido, etiquetado y listo para encajar. Bootstrap es esa ferretería para hacer páginas web.

⌗

Sistema de rejilla potente

Divide la pantalla en 12 columnas para que coloques tu contenido sin pelear con el CSS.

🛠

Utilidades listas

Cientos de clases ya escritas: márgenes, colores, tipografía, sombras… solo las pones en tu HTML.

📱

Compatible en todos lados

Tu web se ve bien en móvil, tablet y ordenador sin que tengas que preocuparte por cada caso.

⚡

Acelera tu desarrollo

En lugar de empezar desde cero, partes con un kit completo: ahorras horas (y dolores de cabeza).

📚

Documentación enorme

Cada componente, ejemplo y variante está documentada con código copiable en su web oficial.

🧩

Componentes plug-and-play

Botones, formularios, alertas, menús, tarjetas… ya hechos. Solo eliges y los usas.

En una frase Bootstrap es un framework de CSS: una librería de estilos y componentes prefabricados que pegas en tu HTML para construir páginas modernas y responsivas mucho más rápido.
02 / Instalación

¿Cómo se instala?

Hay dos caminos. Uno es para empezar en 30 segundos. El otro es para proyectos más serios donde quieres controlar las versiones.

Vía CDN Recomendado para empezar

Pegas dos líneas en tu HTML y listo. Bootstrap se descarga desde su web oficial.

¿Qué es un CDN? Content Delivery Network (red de distribución de contenido). Un conjunto de servidores repartidos por el mundo que sirven archivos —como Bootstrap— desde el más cercano al usuario, para que carguen rápido. En la práctica: enlazas un fichero alojado en otro servidor, sin tener que descargarlo tú. 
<!-- Dentro de <head> -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">

<!-- Antes de cerrar </body> -->
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>

Con gestor de paquetes Profesional

Si usas Node.js, npm o yarn, Bootstrap se instala como una dependencia más.

# Con npm
npm install bootstrap@5.3.3

# Con yarn
yarn add bootstrap@5.3.3
¿Cuál elijo? Si estás aprendiendo o haciendo una página rápida, CDN. Si trabajas en un proyecto con build (React, Vue, Vite…) usa npm.
03 / Rejilla

El sistema de rejilla.

Bootstrap parte el ancho de la pantalla en 12 columnas invisibles. Tu trabajo es decir cuántas columnas ocupa cada bloque de tu contenido. Si todos los bloques de una fila suman 12, ocupan toda la pantalla.

La jerarquía oficial

.container → caja exterior con márgenes laterales
.row → fila horizontal
.col → columna dentro de la fila

Variantes del contenedor:

.container tiene márgenes laterales automáticos.
.container-fluid ocupa el 100% del ancho.

Ejemplo mínimo

<div class="container">
  <div class="row">
    <div class="col-6">Mitad izquierda</div>
    <div class="col-6">Mitad derecha</div>
  </div>
</div>

¿Por qué col-6? Porque 6 + 6 = 12. Cada columna ocupa la mitad.

04 / Responsive

    
Breakpoints: una web, todas las pantallas.

    

      Bootstrap usa el enfoque mobile-first: primero diseñas para móvil,
      luego añades reglas para pantallas más grandes. Cada prefijo (sm,
      md,
      lg…) activa un comportamiento a partir de cierto ancho.
    


    

      
        

          Abreviatura
          Tamaño mínimo
          Dispositivo
          Ejemplo de uso
        

      
      
        
col-0pxExtra pequeñoMóviles muy pequeños

        
col-sm-576pxPequeñoMóviles en horizontal

        
col-md-768pxMedianoTablets

        
col-lg-992pxGrandePortátiles

        
col-xl-1200pxExtra grandeMonitores estándar

        
col-xxl-1400pxMuy grandePantallas amplias

      
    


    

      
¿Cómo se combinan?

      
Puedes apilar varias clases para que un bloque cambie según la pantalla. Mira este caso típico:

      
<div class="col-12 col-md-6 col-lg-4">...</div>

      

        

          📱 En móvil
          
ocupa 12/12 (toda la fila)

        

        

          💻 En tablet
          
ocupa 6/12 (la mitad)

        

        

          🖥 En portátil+
          
ocupa 4/12 (un tercio)

06 / Personalizar

    
¿Y si quiero mi propio estilo?

    

      Bootstrap te da una base, pero no te ata. Puedes añadir tus propias clases
      junto a las suyas para sobreescribir colores, tamaños, bordes… lo que quieras.
    


    

      

        
El truco: clases extra en el HTML

        
Mantienes la clase de Bootstrap y añades una tuya con los cambios.

        
<!-- HTML -->
<button class="btn btn-primary btn-reserva-gimnasio">
  Reservar
</button>

/* Tu CSS */
.btn-reserva-gimnasio {
  background: #ff6b6b;
  border-radius: 999px;
  text-transform: uppercase;
  letter-spacing: 0.1em;
}
