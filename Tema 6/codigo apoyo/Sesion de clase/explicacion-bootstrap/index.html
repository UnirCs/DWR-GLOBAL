Clases Bootstrap usadas en esta cabecera
  • container-fluid Contenedor a ancho completo (100%).
  • py-4 Padding vertical tamaño 4 (arriba y abajo).
  • mx-auto Centra el contenedor usando margen horizontal automático.
  • mb-4 Margen inferior tamaño 4.
  • d-flex Activa flexbox.
  • flex-wrap Permite que los hijos salten de línea.
  • justify-content-between Separa extremos (izquierda/derecha) con espacio en medio.
  • align-items-start Alinea items al inicio vertical (arriba).
  • align-items-center Centra items verticalmente.
  • gap-2 / gap-3 Espaciado uniforme entre hijos (tamaño 2 o 3).
  • h3 Utilidad tipográfica: tamaño visual equivalente a un h3.
  • mb-2 Margen inferior tamaño 2.
  • mb-0 Sin margen inferior.
  • form-check Estructura para checkbox/radio con label.
  • form-switch Variante visual del checkbox como switch.
  • form-check-input Estilo del input dentro de form-check.
  • form-check-label Estilo del label dentro de form-check.
  • form-label Estilo de etiquetas de formulario.
  • small Texto más pequeño.
  • text-muted Texto atenuado (gris).
