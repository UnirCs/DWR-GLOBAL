Este ejemplo usa rem (root em) para tamaños de fuente y em para los breakpoints.

Ahora el texto es legible en móvil y se adapta al tamaño de fuente preferido del usuario.

Breakpoint: @media (min-width: 90em)

Breakpoint: @media (min-width: 64em)

📱 Tablet

Ancho entre 48em y 64em (≈768px - 1023px)

Breakpoint: @media (min-width: 48em)

Comparación: PX vs REM

❌ Con Píxeles (px)

  • Tamaño fijo que no respeta preferencias del usuario
  • Problemas de accesibilidad
  • Texto ilegible en móvil cuando se usan valores pequeños
  • No se adapta si el usuario cambia el tamaño de fuente
body {
    font-size: 10px; /* ¡Error! */
}

@media (max-width: 768px) {
    /* Breakpoint fijo */
}

✅ Con REM/EM

  • Respeta preferencias de tamaño de fuente
  • Mejor accesibilidad
  • Texto siempre legible en todos los dispositivos
  • Se adapta a las necesidades del usuario
body {
    font-size: 1rem; /* ¡Correcto! */
}

@media (width < 48em) {
    /* Breakpoint relativo */
}

Beneficios de Usar Unidades Relativas

♿

Accesibilidad

Los usuarios con problemas de visión pueden ajustar el tamaño de fuente en su navegador.

📐

Escalabilidad

Todo el diseño escala proporcionalmente manteniendo las relaciones de tamaño.

🎯

Consistencia

Los breakpoints se ajustan según el contexto del usuario, no valores arbitrarios.

🔍

Preferencias de Fuente

REM respeta cuando el usuario cambia el tamaño de fuente en las preferencias del navegador. PX ignora estas preferencias de accesibilidad.
