Especificidad CSS

Entendiendo qué regla se aplica cuando hay conflictos

¿Qué es la Especificidad?

La especificidad determina qué regla CSS se aplica cuando múltiples reglas apuntan al mismo elemento.

Se calcula como: (inline, IDs, clases/atributos, elementos)

Ejemplo 1: Selector de Elemento vs Clase

Este párrafo tiene la clase "texto"

Reglas aplicadas:

p { color: blue; } → Especificidad: 0,0,0,1
.texto { color: red; } → Especificidad: 0,0,1,0

✅ Gana: .texto (mayor especificidad) → Color ROJO

Ejemplo 2: Clase vs ID

Este párrafo tiene clase "texto" e ID "parrafo-especial"

Reglas aplicadas:

.texto { color: red; } → Especificidad: 0,0,1,0
#parrafo-especial { color: green; } → Especificidad: 0,1,0,0

✅ Gana: #parrafo-especial (ID tiene más peso) → Color VERDE

Ejemplo 3: Selector Descendente

Este párrafo está dentro de un div con clase "contenedor"

Reglas aplicadas:

.texto { color: red; } → Especificidad: 0,0,1,0
.contenedor .texto { color: purple; } → Especificidad: 0,0,2,0

✅ Gana: .contenedor .texto (más clases) → Color MORADO

Ejemplo 4: Elemento + Clase vs Solo Clase

Este párrafo tiene clase "resaltado"

Reglas aplicadas:

.resaltado { color: orange; } → Especificidad: 0,0,1,0
p.resaltado { color: brown; } → Especificidad: 0,0,1,1

✅ Gana: p.resaltado (clase + elemento) → Color MARRÓN

Ejemplo 5: Múltiples Clases

Este párrafo tiene dos clases: "importante" y "destacado"

Reglas aplicadas:

.importante { color: blue; } → Especificidad: 0,0,1,0
.importante.destacado { color: teal; } → Especificidad: 0,0,2,0

✅ Gana: .importante.destacado (dos clases) → Color VERDE AZULADO

Ejemplo 6: ID vs Múltiples Clases

Este párrafo tiene un ID y tres clases

Reglas aplicadas:

.importante.destacado.resaltado { color: orange; } → Especificidad: 0,0,3,0
#texto-unico { color: darkblue; } → Especificidad: 0,1,0,0

✅ Gana: #texto-unico (un solo ID supera cualquier cantidad de clases) → Color AZUL OSCURO

Ejemplo 7: Inline Style (Máxima Especificidad)

Este párrafo tiene estilo inline

Reglas aplicadas:

#parrafo-inline { color: green; } → Especificidad: 0,1,0,0
style="color: crimson" → Especificidad: 1,0,0,0

✅ Gana: style inline (máxima especificidad) → Color CARMESÍ

Ejemplo 8: !important (Rompe Todo)

Este párrafo tiene clase "forzado"

Reglas aplicadas:

.forzado { color: gray !important; } → Especificidad: ∞
p { color: black; } → Especificidad: 0,0,0,1

✅ Gana: .forzado con !important (ignora especificidad) → Color GRIS

⚠️ EVITA !important: Rompe el flujo natural de la cascada y dificulta el mantenimiento.

📊 Resumen de Especificidad

Selector Especificidad Ejemplo
Inline style 1,0,0,0 style="color: red"
ID 0,1,0,0 #miID
Clase, atributo, pseudo-clase 0,0,1,0 .miClase, [type="text"], :hover
Elemento, pseudo-elemento 0,0,0,1 p, div, ::before
Universal, combinadores 0,0,0,0 *, +, >, ~

📋 Reglas de Oro

  • ✅ A mayor especificidad, mayor prioridad
  • ✅ Con igual especificidad, gana el último definido (cascada)
  • ✅ Un ID siempre gana sobre cualquier cantidad de clases
  • ✅ El estilo inline tiene la máxima especificidad (sin !important)
  • ⚠️ !important rompe todo el sistema, úsalo solo como último recurso
  • 💡 Mantén la especificidad baja para facilitar el mantenimiento
