⚠️ Media Queries: Rangos Mal Definidos

Ejemplo de cómo NO hacer media queries - Cascada CSS rota

🚨 ¡ATENCIÓN! Este es un ANTI-PATRÓN

Este archivo demuestra ERRORES COMUNES al definir media queries con rangos que se solapan.

Estos errores rompen la cascada CSS y causan comportamientos impredecibles.

NO uses este código en producción. Está aquí solo con fines educativos.

Cada media query usa un selector CSS diferente con distinta especificidad, pero debido a los solapamientos, el último selector definido en el código "gana" por cascada, NO el más específico. Esto hace el código difícil de depurar.

Problemas Causados por los Solapamientos

❌ Problema 1: Rangos que se Solapan

/* ❌ MAL */
/* Móvil: 0-768px */
@media (max-width: 768px) { ... }

/* Tablet: 600-1024px */
@media (min-width: 600px) and (max-width: 1024px) { ... }

/* Desktop: 900px+ */
@media (min-width: 900px) { ... }

Problema: Entre 600-768px se aplican AMBOS breakpoints (móvil Y tablet). Entre 900-1024px se aplican AMBOS (tablet Y desktop). Esto causa conflictos.

❌ Problema 2: Especificidad Confusa

Observa el párrafo arriba "El color de este texto no está claro": Redimensiona lentamente la ventana y verás cómo cambia de color de forma impredecible. Aunque algunos selectores tienen diferente especificidad, el último en el código "gana" por cascada.

Selectores CSS Usados:

/* Móvil (0-768px) - Color AZUL */
.debug-text { color: #0984e3; }
/* Especificidad: 0,0,1,0 */

/* Tablet (600-1024px) - Color VERDE */
section .debug-text { color: #00b894; }
/* Especificidad: 0,0,2,0 - ¡MÁS específico! */

/* Desktop (900px+) - Color MORADO */
.device-indicator .debug-text { color: #6c5ce7; }
/* Especificidad: 0,0,2,0 - Igual que tablet */
/* Pero GANA por cascada (está DESPUÉS) */

/* Large (1200px+) - Color NARANJA */
p.debug-text { color: #e17055; }
/* Especificidad: 0,0,1,1 - MENOS que otros */
/* ¡Pero GANA igualmente por cascada! */

Problema: En las zonas de solape, el último estilo definido "gana" debido a la cascada, NO el más específico. Esto es impredecible y difícil de debuggear.

❌ Problema 3: Gaps (Huecos)

/* ❌ MAL - Hay un gap entre 768 y 900 */
@media (max-width: 768px) {
    /* Estilos móvil */
}

@media (min-width: 900px) {
    /* Estilos desktop */
}

/* Entre 769-899px NO hay estilos definidos! */

Problema: Rangos discontinuos dejan "huecos" donde no se aplican estilos específicos, causando diseños rotos en ciertos tamaños.

✅ La Solución Correcta

❌ INCORRECTO (Solapado)

/* Rangos que se solapan */
@media (max-width: 768px) { }
@media (min-width: 600px)
   and (max-width: 1024px) { }
@media (min-width: 900px) { }

📋 Mejores Prácticas

  • ✅ Usa mobile-first: Prioriza min-width, sin max-width. Este ultimo es mas restrictivo
  • ✅ Define breakpoints consecutivos sin huecos ni solapamientos
  • ✅ Limita el número de breakpoints
  • ✅ Documenta claramente qué rango cubre cada breakpoint
  • ❌ EVITA usar min-width y max-width juntos en el mismo breakpoint
  • ❌ EVITA crear rangos que se solapan
  • ❌ EVITA dejar huecos entre breakpoints
