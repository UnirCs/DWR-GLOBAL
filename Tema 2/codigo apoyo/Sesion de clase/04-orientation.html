Media Queries: Orientación

Portrait (Vertical) vs Landscape (Horizontal)

¿Qué es la orientación?

La orientación se refiere a si el dispositivo está en modo vertical (portrait) u horizontal (landscape).

Esta característica es especialmente útil para tablets y móviles que pueden rotar.

📱

Modo Portrait (Vertical)

La altura es mayor que el ancho

@media (orientation: portrait)

Alto > Ancho

📱🔄

Modo Landscape (Horizontal)

El ancho es mayor que la altura

@media (orientation: landscape)

Ancho > Alto

Dos columnas

Sintaxis de Orientación

Portrait (Vertical)

@media (orientation: portrait) {
    /* Estilos cuando la altura > ancho */
    .content {
        flex-direction: column;
    }
}

Landscape (Horizontal)

@media (orientation: landscape) {
    /* Estilos cuando el ancho > altura */
    .content {
        flex-direction: row;
    }
}

💡 Consejo

Combina orientación con tamaño de pantalla para mejores resultados:

@media (max-width: 48em) and (orientation: landscape) {
    /* Móvil en horizontal */
    header {
        height: 3rem; /* Reducir altura del header */
    }
}
