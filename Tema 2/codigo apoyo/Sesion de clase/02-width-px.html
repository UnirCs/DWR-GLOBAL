Media Queries: Width con Píxeles

Comparando notación antigua (min-width/max-width) con notación nueva (rangos)

⚠️ Problema de Tamaños Fijos

Este ejemplo usa píxeles (px) en lugar de unidades relativas como em o rem.

En dispositivos móviles, el texto se verá DEMASIADO PEQUEÑO porque no escala con el tamaño de fuente del usuario.

¿En qué dispositivo estás?

🖥️ Escritorio

Ancho mayor a 1024px

Usando notación antigua: @media (min-width: 1025px)

📱 Tablet

Ancho entre 768px y 1024px

Usando notación antigua: @media (min-width: 768px) and (max-width: 1024px)

📱 Móvil

Ancho menor a 768px

Usando notación nueva (rangos): @media (width < 768px)

⚠️ El texto aquí se ve MUY PEQUEÑO porque usa 10px fijos!

Sintaxis Utilizada

Notación Antigua (Legacy)

/* Mínimo */
@media (min-width: 768px) {
    /* Estilos para 768px y más */
}

/* Máximo */
@media (max-width: 767px) {
    /* Estilos para menos de 768px */
}

/* Rango */
@media (min-width: 768px) and (max-width: 1024px) {
    /* Estilos entre 768px y 1024px */
}

Notación Nueva (Media Queries Level 4)

/* Mínimo */
@media (width >= 768px) {
    /* Estilos para 768px y más */
}

/* Máximo */
@media (width < 768px) {
    /* Estilos para menos de 768px */
}

/* Rango */
@media (768px <= width <= 1024px) {
    /* Estilos entre 768px y 1024px */
}
