¿Qué son las Media Queries?

Las media queries son una característica de CSS3 que permite aplicar estilos diferentes según las características del dispositivo donde se visualiza la página web.

En este ejemplo, verás cómo los estilos cambian entre la visualización en pantalla (screen) y la impresión (print).

Instrucciones

Para ver las diferencias:

  • Visualiza esta página normalmente en tu navegador
  • Luego, usa la función de Vista Previa de Impresión (Ctrl+P o Cmd+P)
  • Observa cómo cambian los colores y la visibilidad de elementos

Diferencias entre Screen y Print

Screen: Optimizado para visualización en pantalla con colores vivos y elementos interactivos.

Print: Optimizado para impresión con colores neutros, fuentes serif y sin elementos innecesarios como navegación.
