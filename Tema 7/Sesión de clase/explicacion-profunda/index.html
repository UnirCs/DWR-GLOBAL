Qué es, cómo funciona y características avanzadas

1) ¿Qué es Tailwind CSS?

Framework utility-first: construye interfaces sin escribir CSS personalizado

Tailwind proporciona clases predefinidas para cada propiedad CSS. En lugar de escribir estilos personalizados, combinas utilidades pequeñas y reutilizables directamente en el HTML.

❌ CSS Tradicional

.card { padding: 1.5rem; border-radius: 1rem; background: white; border: 1px solid #e2e8f0; }

✅ Tailwind

<div class="p-6 rounded-lg bg-white border border-slate-200"> Card </div>

💡 Utility-First: Clases reutilizables en HTML. Prototipado rápido, consistencia visual, escalable.

2) Ventajas y Desventajas

✅ Ventajas

  • • Prototipado rápido sin escribir CSS
  • • Consistencia visual con tokens compartidos
  • • Responsive: md:, lg: sin media queries
  • • Estados incorporados: hover:, focus:, dark:
  • • Purging automático elimina CSS no usado

⚠️ Desventajas

  • • HTML con muchas clases
  • • Curva de aprendizaje
  • • Requiere build (PostCSS, Vite, Next.js)
  • • CSS no está separado del HTML
  • • Usa @apply cuando repites clases

5) Directivas

Las directivas son instrucciones especiales que le dicen a Tailwind qué hacer. Son como "comandos mágicos" para organizar y reutilizar estilos.

@apply — "Guarda estas clases en una regla"

¿Qué es? Es como crear un atajo. Si repites las mismas clases en muchos lugares, las guardas en una regla CSS reutilizable.

❌ Sin @apply (Repetición)

<button class="px-4 py-2 rounded-lg bg-indigo-600 text-white font-semibold"> Click 1 </button> <button class="px-4 py-2 rounded-lg bg-indigo-600 text-white font-semibold"> Click 2 </button>

✅ Con @apply (Limpio)

/* Archivo CSS */ @layer components { .btn-primary { @apply px-4 py-2 rounded-lg bg-indigo-600 text-white font-semibold; } } /* Archivo HTML */ <button class="btn-primary"> Click 1 </button> <button class="btn-primary"> Click 2 </button>

💡 Resumen: @apply = "Crea una clase CSS usando utilidades de Tailwind"

@layer — "Organiza los estilos en carpetas"

¿Qué es? Los estilos CSS tienen un orden de importancia. @layer te ayuda a decirle a Tailwind dónde colocar tus reglas para evitar conflictos.

base

Estilos fundamentales (h1, p, body)

components

Componentes reutilizables (botones, cards)

utilities

Utilidades pequeñas (p-4, text-lg)

@layer base { h1 { @apply text-4xl font-bold mb-4; } p { @apply text-base leading-relaxed; } } @layer components { .btn { @apply px-4 py-2 rounded-lg; } .card { @apply border rounded-xl p-6; } } @layer utilities { .flex-center { @apply flex items-center justify-center; } }

💡 Resumen: @layer = "Agrupa tus estilos en base, components o utilities"

@tailwind — "Inyecta los estilos de Tailwind"

¿Qué es? Este comando le dice a tu archivo CSS dónde insertar todos los estilos de Tailwind. Va al inicio de tu archivo CSS.

/* En tu archivo input.css */ @tailwind base; /* Estilos base */ @tailwind components; /* Componentes */ @tailwind utilities; /* Utilidades (lo más grande) */

💡 Resumen: @tailwind = "Carga los estilos de Tailwind en tu CSS"

6) Variants

Los variants son prefijos que aplican estilos según una condición: cuando pasas el ratón, en pantallas grandes, en modo oscuro... Es como decir "si ocurre X, entonces aplica este estilo".

Variants de Interacción (Cosas que hace el usuario)

🖱️ hover: — "Cuando pasas el ratón"

Cambia el estilo cuando el usuario pasa el ratón sobre algo.

<button class="bg-indigo-600 hover:bg-indigo-700"> Hover sobre mí </button>

⌨️ focus: — "Cuando tiene foco (clickeado)"

Cambia el estilo cuando el usuario hace click o tab en un input.

<input class="border focus:ring-2 focus:ring-green-400" />

🔥 active: — "Mientras está siendo pulsado"

Cambia el estilo mientras el usuario tiene pulsado el botón.

<button class="bg-purple-600 active:scale-95"> Presiona </button>

🚫 disabled: — "Cuando está deshabilitado"

Aplica un estilo a los botones o inputs deshabilitados.

<button disabled class="disabled:opacity-50"> No disponible </button>

Variants Responsive (Tamaños de pantalla)

Prefijai el nombre con sm:, md:, lg: para aplicar estilos solo en ciertos tamaños de pantalla.

<div class="grid-cols-1 md:grid-cols-2 lg:grid-cols-3"> <div>Box 1</div> <div>Box 2</div> <div>Box 3</div> </div>

Resultado:

📱 Móvil: 1 columna

🖥️ Tablet (md): 2 columnas

💻 Desktop (lg): 3 columnas

Box 1
Box 2
Box 3

dark: — Modo Oscuro

Prefija con dark: para cambiar estilos cuando está en modo oscuro.

<div class="bg-white dark:bg-slate-800 text-slate-900 dark:text-white"> Texto adaptado al tema </div>
Mira cómo cambio con el botón 🌙

📋 Resumen de Variants

De Interacción:

  • • hover: = al pasar ratón
  • • focus: = cuando tiene foco
  • • active: = mientras se pulsa
  • • disabled: = deshabilitado

De Pantalla & Tema:

  • • sm:, md:, lg: = breakpoints
  • • dark: = modo oscuro
  • • portrait:, landscape: = orientación
