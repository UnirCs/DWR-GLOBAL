¿Cómo gestiono hover/dark/responsive? +

Con variants: hover:, md:, dark:, group-hover:, etc.

Setup

tailwind.config.js + @layer/@apply/@variants

Qué estás viendo aquí

  • @layer: colocas tus estilos en base/components/utilities.
  • @apply: compones utilidades en clases tipo .btn, .card.
  • @variants: directiva legacy (v1/v2) para generar variantes de una regla CSS. En Tailwind moderno normalmente usas prefijos (hover:, md:, etc.) o creas variants con plugins / directivas nuevas.

Nota rápida: @variants aparece en la documentación antigua (Tailwind v1/v2). En proyectos actuales suele sustituirse por variants en config (v2), plugins (v3), o directivas modernas como @custom-variant en v4.

tailwind.config.js (ejemplo típico)

/** @type {import('tailwindcss').Config} */
module.exports = {
  darkMode: 'class',
  content: [
    './src/**/*.{html,js,ts,jsx,tsx,vue}',
  ],
  theme: {
    extend: {
      fontFamily: {
        ui: ['ui-sans-serif','system-ui','-apple-system','Segoe UI','Roboto','Helvetica','Arial'],
      },
      // Ejemplo: tokens propios
      borderRadius: {
        'xl': '0.9rem',
        '2xl': '1.25rem',
      },
    },
  },
  plugins: [
    // require('@tailwindcss/forms'),
    // require('@tailwindcss/typography'),
  ],

  // (LEGACY v2) Configurar variantes que se generan para utilidades concretas:
  // variants: {
  //   extend: {
  //     backgroundColor: ['active'],
  //     opacity: ['disabled'],
  //   },
  // },
};

app.css (cómo usar @layer + @apply + @variants)

@tailwind base;
@tailwind components;
@tailwind utilities;

/* 1) BASE: estilos globales */
@layer base {
  html { @apply bg-slate-50 text-slate-900; }
  html.dark { @apply bg-slate-950 text-slate-50; }
}

/* 2) COMPONENTS: clases reutilizables con @apply */
@layer components {
  .card {
    @apply rounded-2xl border border-slate-200 bg-white p-6 shadow-sm
           dark:border-slate-800 dark:bg-slate-900;
  }

  .btn {
    @apply inline-flex items-center justify-center gap-2 rounded-xl px-4 py-2
           text-sm font-semibold transition active:scale-[0.98];
  }

  .btn-primary {
    @apply btn bg-slate-900 text-white shadow-sm hover:bg-slate-800
           dark:bg-white dark:text-slate-900 dark:hover:bg-slate-200;
  }

  .btn-ghost {
    @apply btn border border-slate-200 bg-white text-slate-900 hover:bg-slate-50
           dark:border-slate-800 dark:bg-slate-900 dark:text-slate-50 dark:hover:bg-slate-800;
  }
}

/* 3) UTILITIES: utilidades custom (si hace falta) */
@layer utilities {
  .text-balance { text-wrap: balance; }

  /* @variants (LEGACY v1/v2)
     Genera variantes como hover:.glass, focus:.glass, etc.
     En Tailwind moderno normalmente prefieres usar prefijos en el HTML o plugins. */
  @variants hover, focus, dark {
    .glass {
      @apply bg-white/70 backdrop-blur border border-white/40;
    }
  }
}

/* Uso en HTML (cuando compilas):
  
...

  
  
...

*/
