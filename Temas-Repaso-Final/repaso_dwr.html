1 Mobile First ~5 min

Estrategia de diseño que parte de la pantalla más pequeña y escala hacia arriba.

Mobile First significa diseñar pensando primero en cómo se presenta y se consume el contenido en el móvil, y luego ir añadiendo complejidad para pantallas mayores. No es un capricho estético: en una pantalla pequeña el espacio es escaso, así que te obliga a decidir qué contenido es realmente esencial desde el principio.

¿Por qué se prioriza el móvil?

  • Porque el contenido debe ser claro y usable en pantallas pequeñas desde el inicio.
  • Si funciona en lo más limitado, escalar hacia arriba (añadir columnas, espacio…) es fácil.
  • El camino inverso —quitar cosas de un diseño de escritorio— suele dejar interfaces apretadas y rotas.

2 Media Queries y Breakpoints ~5 min

El mecanismo de CSS que aplica estilos distintos según el dispositivo.

Una media query no mira el HTML ni el servidor: evalúa las características del viewport / dispositivo (ancho, alto, orientación, etc.) y, si se cumple la condición, aplica un bloque de estilos. Sirven para adaptar los estilos según el tamaño de pantalla.

/* Estilos base (móvil) aplican siempre */
.caja{ flex-direction: column; }

/* A partir de 768px de ancho, cambia */
@media (min-width: 768px){
  .caja{ flex-direction: row; }
}

Los breakpoints son esos puntos de ruptura (768px, 1024px…) donde el diseño cambia para adaptarse a distintos tamaños de pantalla. Con Mobile First se usa min-width (de pequeño a grande); con Desktop First, max-width.

Truco mental "media" = medio/dispositivo. La query pregunta al dispositivo "¿cuánto mides?" y responde con estilos.

3 Flexbox ~7 min

Sistema de alineación y distribución en una sola dimensión. Bloque con bastante peso.

Flexbox organiza y alinea elementos a lo largo de un único eje (una fila o una columna). Es ideal para barras de navegación, botoneras, tarjetas en línea… cualquier cosa que vaya "en una dirección".

El eje principal depende de flex-direction

  • row → eje principal horizontal (izquierda → derecha).
  • column → eje principal vertical (arriba → abajo).

4 CSS Grid · fundamentos ~7 min

Sistema de layout bidimensional: controla filas y columnas a la vez.

La diferencia que MÁS se pregunta Grid trabaja en dos dimensiones (filas + columnas). Flexbox solo en una. Esa es la distinción fundamental entre ambos.

Propiedades base

PropiedadQué define
grid-template-columnsLa estructura de columnas (cuántas y de qué tamaño).
grid-template-rowsLa estructura de filas.
gapSepara filas y columnas (NO es padding ni margin).
grid-template-areasNombra zonas para entender y reorganizar el layout visualmente.
.layout{
  display: grid;
  grid-template-columns: 1fr 1fr 1fr; /* 3 columnas iguales */
  gap: 8px; /* hueco entre celdas */
}

5 CSS Grid · funciones y responsive ~6 min

Funciones que hacen el grid flexible sin media queries: fr, minmax() y repeat().

La unidad fr (fraction)

Representa una fracción del espacio disponible. 1fr 1fr = dos columnas iguales; 2fr 1fr = la primera el doble de ancha.

La función minmax() — muy preguntada

Memorízalo bien minmax(200px, 1fr) = tamaño mínimo de 200px y máximo de 1fr (el espacio restante). Cuidado con la opción trampa que invierte mínimo y máximo.
.galeria{
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
  gap: 10px;
}

Esto crea una galería que se adapta sola: mete tantas columnas de mínimo 200px como quepan, y reparte el sobrante. Sin escribir una sola media query.

7 Tailwind CSS ~5 min

Framework utility-first: estilas componiendo clases utilitarias directamente en el HTML.

A diferencia de Bootstrap (que da componentes ya montados), Tailwind es utility-first: te da pequeñas clases de un solo propósito y tú las combinas. Construyes el diseño en el propio HTML.

Una clase = una utilidad
flexflex-colgap-4p-4bg-blue-500text-whiterounded-lg

Cada una hace una cosa concreta. El estilo final es la suma de todas.

Dos cosas que se preguntan

ConceptoEn Tailwind
Flexbox en columnaflex-col = Flexbox en dirección columna.
BreakpointsCon prefijo en la clase: md:, lg:… (NO con @media).
<!-- columna en móvil, fila a partir de md (768px) -->
<div class="flex flex-col md:flex-row gap-4"> ... </div>
Lee el prefijo así md:flex-row = "a partir del breakpoint md, aplica flex-row". El prefijo es la condición responsive.

8 SASS / SCSS ~5 min

Preprocesador que añade a CSS variables, anidamiento, mixins y modularidad. Se compila a CSS normal.

Mixins

Un mixin sirve para reutilizar bloques de estilos, admitiendo parámetros. Defines una vez, usas muchas con valores distintos.

@mixin boton($color){
  background: $color;
  padding: 8px 16px;
  border-radius: 6px;
}
.primario{ @include boton(#0055a5); }
.peligro{  @include boton(#c0392b); }

Partials

Un partial es un archivo .scss pensado para ser importado en otros (su nombre empieza por _, p. ej. _botones.scss). No se compila por sí solo: sirve para organizar el código en piezas.

Cuidado con el anidamiento excesivo

Problema típico Anidar demasiados niveles genera selectores con demasiada especificidad, difíciles de sobrescribir y mantener.
/* ❌ Demasiado anidado */
.nav{
  .lista{
    .item{
      .enlace{
        color: red; /* muy específico */
      }
    }
  }
}
/* ✅ Plano y mantenible */
.nav-enlace{
  color: red;
}
¿Para qué se utiliza un mixin en SASS?
Para declarar variables globales
Para reutilizar bloques de estilos con parámetros
Para importar archivos

9 Accesibilidad · contenido e imágenes ~6 min

Hacer que la web pueda usarla el mayor número de personas posible. Bloque con varias preguntas.

No transmitir información solo con el color

Hay usuarios que no perciben el color (daltonismo, lectores de pantalla…). Si el color es la única señal, esa información se pierde. Hay que reforzarla con texto, iconos o formas.

❌ Solo color

Disponible
Agotado

Quien no distingue verde/rojo no entiende nada.
✅ Color + texto/icono

✔ Disponible
✘ Agotado

La señal no depende solo del color.

El atributo alt

El atributo alt describe la imagen para los lectores de pantalla y se muestra si la imagen no carga. Es el atributo correcto para una imagen informativa (no title, ni role, ni aria-hidden).

<img src="grafico-ventas.png"
     alt="Ventas subieron un 20% en 2025">
Matiz Si una imagen es puramente decorativa, se usa alt="" (vacío) para que los lectores de pantalla la ignoren.

HTML semántico

Usar etiquetas con significado (<header>, <nav>, <main>, <article>, <footer>) en lugar de <div> para todo mejora la accesibilidad y el SEO: los lectores de pantalla y los buscadores entienden la estructura.

¿Para qué sirve el atributo alt en una imagen?
Para añadir estilos a la imagen
Para describirla si no carga o para lectores de pantalla
Para cambiar su tamaño

10 Accesibilidad · interacción y teclado ~6 min

Definición, contraste, foco y navegación por teclado.

¿Qué es la accesibilidad web?

Definición Que una web pueda ser usada por el mayor número de personas posible, incluyendo personas con discapacidad. No es "que se vea igual en todos los navegadores" ni "que cargue más rápido".

Contraste de color

Texto y fondo necesitan suficiente contraste para ser legibles por personas con baja visión:

Contraste insuficiente ❌
Contraste correcto ✅

El foco y la navegación por teclado

Muchos usuarios navegan con Tab, sin ratón. El outline (el borde que aparece al enfocar) es su guía visual.

Error grave Si eliminas outline sin poner una alternativa, perjudicas la navegación por teclado: el usuario deja de ver dónde está.
Pulsa Tab para mover el foco entre estos botones

Accesibilidad en modales

Un modal accesible debe atrapar el foco mientras está abierto (focus trap): el Tab no debe escaparse a la página de detrás. Así el usuario de teclado no se "pierde" fuera del diálogo.

¿Qué ocurre si se elimina outline sin alternativa?
Nada relevante
Mejora estética sin consecuencias
