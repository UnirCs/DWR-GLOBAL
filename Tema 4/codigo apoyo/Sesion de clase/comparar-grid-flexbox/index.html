Flexbox vs Grid – Comparativa visual

Playground didáctico para entender las diferencias entre Flexbox y Grid. Puedes alternar entre ambos en cada sección y editar el CSS en tiempo real para ver cómo cambia el layout.

1. Unidimensional (Flex) vs Bidimensional (Grid)

Flexbox trabaja en una dimensión (fila o columna): primero reparte en el eje principal y luego puede envolver (wrap). Grid trabaja en dos dimensiones: defines columnas y filas y cada ítem cae en una “celda”.

2. Alineación y reparto de espacio

En Flexbox, justify-content actúa en el eje principal (fila o columna) y align-items en el eje cruzado. En Grid, además de justify-content y align-content (contenedor), puedes usar justify-items y align-items para alinear el contenido de cada celda.

3. Layout real: cabecera + sidebar + contenido

Un layout típico con cabecera y sidebar se puede construir tanto con Flexbox como con Grid. Flexbox suele ser más directo cuando solo piensas en fila/columna; Grid resulta más expresivo cuando quieres controlar filas y columnas explícitas.
