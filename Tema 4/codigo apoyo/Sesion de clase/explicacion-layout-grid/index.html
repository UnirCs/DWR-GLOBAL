CSS Grid – Guía visual interactiva

Playground didáctico para aprender CSS Grid modificando el código en tiempo real. Verás cómo se generan columnas y filas, las diferencias entre valores como auto, 1fr, px o minmax(), qué diferencia hay entre auto-fit y auto-fill, y cómo definir diferentes áreas para crear un layout completo.

1. Contenedor Grid: columnas y filas

Grid se activa con display: grid. Con grid-template-columns decides cuántas columnas hay y cómo se reparte el ancho. Las filas se generan solas: si tienes 6 ítems y 3 columnas, tendrás 2 filas; si reduces a 2 columnas, tendrás 3 filas, etc.

Regla mental rápida: más columnas ⇒ menos filas; menos columnas ⇒ más filas.

Aquí mezclamos columnas fijas (px) con columnas flexibles (1fr). 1fr reparte el espacio libre, mientras que un valor fijo en px ocupa siempre lo mismo. Para las filas, auto toma la altura que necesite el contenido.

3. repeat(), fr, auto-fit, auto-fill, minmax()

Aquí vemos cómo hacer un grid responsive con autoajuste de columnas usando minmax(), auto-fit y auto-fill. minmax(220px, 1fr) marca el rango de cada columna (mínimo 220px, máximo una fracción del espacio). Diferencia clave: auto-fit colapsa las columnas vacías y hace que las tarjetas se estiren; auto-fill reserva también las columnas “fantasma”, aunque no haya contenido.

5. Áreas del layout con grid-template-areas

Con grid-template-areas defines el layout como si dibujaras un mapa: cabecera, menú lateral, contenido, footer… Luego cada elemento se engancha a una zona con grid-area. Lo potente es que puedes reordenar el layout sin tocar el HTML, solo cambiando la plantilla.
