CSS Grid – Guía visual interactiva

Playground didáctico para aprender CSS Grid modificando el código en tiempo real. Verás cómo se generan columnas y filas, las diferencias entre valores como auto, 1fr, minmax(), qué diferencia hay entre auto-fit y auto-fill, y cómo definir áreas completas para un layout real.

1. Contenedor Grid: columnas y filas

Grid se activa con display: grid. Con grid-template-columns decides cuántas columnas hay y cómo se reparte el ancho. Las filas se generan solas.

Es decir: más columnas ⇒ menos filas; menos columnas ⇒ más filas.

3. auto-fit vs auto-fill + minmax()

Ambos calculan cuántas columnas caben con un tamaño mínimo, por ejemplo minmax(60px, 1fr), pero se comportan distinto con las columnas sin contenido:

  • auto-fit colapsa columnas vacías y reparte el espacio entre las que tienen contenido. El usuario ve solo lo que existe.
  • auto-fill mantiene columnas potenciales aunque no haya ítems. El usuario intuye capacidad o huecos “donde podría haber más”.

Desde el punto de vista de UX: auto-fit es ideal para listados de elementos reales (productos, posts…), mientras que auto-fill es útil cuando quieres representar capacidad (slots, plazas, casillas de calendario…) aunque todavía no estén ocupados.

Ejemplo real: curso con capacidad máxima 12 plazas, pero solo 7 plazas reservadas (las únicas que recibimos desde una API). No generamos huecos a mano en el HTML.

Capacidad: 12 · Reservadas: 7 · Libres: 5 (las libres no existen como elementos, solo como “espacio potencial”).

auto-fit · solo se ve lo que existe, las plazas se estiran

El navegador colapsa las columnas vacías. Solo “cuentan” las 7 plazas reales. El resultado es un grid compacto donde cada “Reservado” ocupa más ancho. Visualmente: perfecto si solo quieres mostrar quién está apuntado, sin insistir en cuántas plazas máximas había.

Ejemplo real auto-fit · Grid de productos (solo importa lo que existe)

Aquí lo que nos interesa es que las tarjetas de producto rellenen el ancho disponible, sin insinuar huecos ni capacidad máxima. auto-fit es perfecto: si hay 2 productos, se verán grandes; si hay 8, cabrán más columnas, pero siempre ocupando todo el ancho del contenedor.
