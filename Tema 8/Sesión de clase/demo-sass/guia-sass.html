¿Qué es SASS?

SASS (Syntactically Awesome Style Sheets) es un preprocesador CSS que te permite escribir estilos de una manera más organizada, reutilizable y mantenible. SASS extiende CSS con características como variables, anidamiento, mixins, funciones, bucles y condicionales.

💡 Información importante: SASS necesita ser compilado a CSS normal antes de que los navegadores puedan interpretarlo. Los navegadores no entienden SASS directamente.

Ventajas de usar SASS:

  • Variables: Define valores una sola vez y úsalos en todo tu proyecto
  • Anidamiento: Estructura tu código de forma jerárquica, refleja la estructura HTML
  • Reutilización: Crea mixins para bloques de código reutilizable
  • Funciones: Realiza cálculos y transformaciones en tu CSS
  • Modularización: Divide tu CSS en múltiples archivos organizados
  • Bucles y condicionales: Automatiza la generación de estilos
  • Herencia: Comparte propiedades entre selectores

⚙️ Instalación y Configuración

Paso 1: Instalar SASS

En tu terminal, ejecuta el siguiente comando:

npm install -g sass

Paso 2: Crear tu estructura de carpetas

Organiza tu proyecto así:

mi-proyecto/ ├── scss/ │ └── main.scss ├── css/ │ └── main.css └── index.html

Paso 3: Compilar SASS a CSS

📌 Compilación Única

Ejecutas el comando una sola vez. SASS convierte tu archivo .scss a .css en ese momento. Si cambias el archivo SCSS después, tienes que ejecutar el comando de nuevo.

sass scss/main.scss css/main.css

Ideal para: Compilar una sola vez al finalizar, o cuando prefieres compilar manualmente.

📌 Compilación Monitorizada (Modo Watch)

El comando se mantiene escuchando cambios en tu carpeta SCSS. Cada vez que modifiques un archivo .scss, SASS automáticamente recompila a CSS sin que tengas que ejecutar el comando de nuevo.

sass --watch scss:css

Ideal para: Desarrollo. Deja este comando activo en una terminal y trabaja sin preocuparte por compilar.

💡 Consejo: Durante el desarrollo, usa el modo watch en una terminal. Cuando termines, presiona Ctrl + C para detenerlo.

Paso 4: Enlazar el CSS en tu HTML

<head> <link rel="stylesheet" href="css/main.css"> </head>
✅ Listo: Ahora escribe SASS en archivos .scss y se compilarán automáticamente a CSS que los navegadores puedan entender.

📦 Variables en SASS

Las variables te permiten almacenar valores (colores, tamaños, fuentes, etc.) y reutilizarlos en todo tu proyecto. Esto facilita mantener consistencia y hacer cambios globales rápidamente.

Ejemplo Visual

Color Primario
Color Secundario
Color Éxito
Color Error

Estos colores están definidos como variables que se reutilizan en todo el proyecto

// _variables.scss // Definir variables $color-primario: #667eea; $color-secundario: #764ba2; $color-exito: #50fa7b; $color-error: #ff6b6b; $font-principal: 'Segoe UI', sans-serif; $font-size-base: 16px; $espaciado: 20px; $radio-borde: 8px;
// main.scss @import 'variables'; body { font-family: $font-principal; font-size: $font-size-base; background: $color-primario; } .boton { background: $color-primario; padding: $espaciado; border-radius: $radio-borde; }

Ventajas de las Variables

  • Mantenibilidad: Cambia un color en un lugar y afecta todo el proyecto
  • Consistencia: Asegura que los valores se repitan en todo el código
  • Escalabilidad: Facilita crecer tu proyecto sin duplicar valores
  • Cálculos: Puedes hacer operaciones matemáticas con variables

🏗️ Anidamiento (Nesting)

El anidamiento permite escribir selectores CSS de forma jerárquica, reflejando la estructura de tu HTML. Esto reduce la repetición de código y lo hace más legible.

Ejemplo Visual

🏠 Header
Logo • Navegación • Botón Login
📄 Sección
Título • Párrafos • Botones
🔗 Navegación
Enlaces activos • Enlaces hover
// componentes/_header.scss header { background: blue; padding: 20px; nav { display: flex; gap: 30px; a { color: white; text-decoration: none; transition: all 0.3s; &:hover { color: yellow; transform: translateY(-2px); } } } }
⚠️ Nota importante: El símbolo & representa el selector padre. En el ejemplo anterior, &:hover se convierte en header nav a:hover.

Casos de uso comunes:

  • Pseudoclases: :hover, :focus, :active, :nth-child()
  • Pseudoelementos: ::before, ::after
  • Media queries: Resonsivo dentro del elemento
  • Clases relacionadas: .elemento--modificador

🔧 Mixins y @include

Los mixins son bloques de código reutilizable que puedes incluir en múltiples lugares. Son perfectos para estilos repetitivos como transiciones, flexbox, gradientes, etc.

Ejemplo Visual - Botones con Mixins

Botón Primario
Botón Secundario
Botón Éxito

Todos usan el mismo mixin de botón base con parámetros diferentes

// _mixins.scss @mixin boton-base { padding: 12px 25px; border-radius: 5px; border: none; cursor: pointer; font-weight: 600; transition: all 0.3s; } @mixin boton-color($bg, $hover) { @include boton-base; background: $bg; color: white; &:hover { background: $hover; transform: translateY(-2px); } }
// componentes/_botones.scss @import '../_mixins'; .btn-primario { @include boton-color(#667eea, #5568d3); } .btn-secundario { @include boton-color(#764ba2, #63408a); } .btn-exito { @include boton-color(#50fa7b, #3fdb67); }

Mixins comunes en proyectos reales:

// Flexbox centrado @mixin flex-center { display: flex; justify-content: center; align-items: center; } // Responsive @mixin tablet { @media (max-width: 768px) { @content; } } // Sombra con parámetro @mixin sombra($intensidad: 0.2) { box-shadow: 0 4px 10px rgba(0, 0, 0, $intensidad); }
// componentes/_card.scss @import '../_mixins'; .header { @include flex-center; @include sombra(0.15); padding: 20px; } .card { @include sombra(0.3); padding: 20px; border-radius: 8px; @include tablet { padding: 10px; } }

⚙️ Funciones en SASS

Las funciones en SASS permiten realizar cálculos y transformaciones. Retornan un valor que puede usarse en propiedades CSS.

Ejemplo Visual - Escala de Colores

Color Base
darken(base, 0%)
Oscuro
darken(base, 10%)
Más Oscuro
darken(base, 25%)
Claro
lighten(base, 10%)
// _variables.scss $color-base: #667eea;
// base/_colores.scss @import '../_variables'; .elemento { background: $color-base; border: 2px solid darken($color-base, 10%); } .elemento-hover { background: lighten($color-base, 5%); } .elemento-disabled { background: desaturate($color-base, 50%); opacity: 0.5; }
// _funciones.scss @function rem($px) { @return ($px / 16) * 1rem; }
// base/_tipografia.scss @import '../_funciones'; .titulo { font-size: rem(32); margin: rem(20) rem(10); }

Funciones integradas en SASS:

Función Descripción Ejemplo
darken($color, $amount) Oscurece un color darken(#667eea, 10%)
lighten($color, $amount) Aclara un color lighten(#667eea, 10%)
saturate($color, $amount) Aumenta la saturación saturate(#667eea, 20%)
desaturate($color, $amount) Reduce la saturación desaturate(#667eea, 50%)
rgba($color, $alpha) Añade transparencia rgba(#667eea, 0.5)
length($list) Longitud de una lista length(1px 2px 3px)
round($number) Redondea un número round(3.5)
str-length($string) Longitud de un string str-length("hello")

Creando funciones personalizadas:

// Función para calcular tamaño responsive @function responsive-size( $mobile, $desktop ) { @return $mobile; } // Función para generar paleta de colores @function shade($color, $level) { @if $level == 'light' { @return lighten($color, 15%); } @else if $level == 'dark' { @return darken($color, 15%); } @else { @return $color; } }

🔄 Bucles en SASS

Los bucles permiten generar CSS automáticamente. SASS soporta @for, @each y @while para iterar y crear múltiples reglas.

Ejemplo Visual - Sistema de Espaciado

Margin Classes:
.m-1 { margin: 5px; }
.m-2 { margin: 10px; }
.m-3 { margin: 15px; }
.m-4 { margin: 20px; }
.m-5 { margin: 25px; }
... Generadas automáticamente con un bucle
// utilidades/_espaciado.scss // Generar clases de margin y padding @for $i from 1 through 5 { .m-#{$i} { margin: ($i * 5px); } .p-#{$i} { padding: ($i * 5px); } } // Resultado compilado: // .m-1 { margin: 5px; } // .m-2 { margin: 10px; } // .m-3 { margin: 15px; } // ...

Bucle @each para listas:

// utilidades/_temas.scss $colores: ( primario: #667eea, secundario: #764ba2, exito: #50fa7b ); @each $nombre, $valor in $colores { .bg-#{$nombre} { background: $valor; color: white; padding: 10px 20px; } } // Resultado compilado: // .bg-primario { background: #667eea; } // .bg-secundario { background: #764ba2; } // .bg-exito { background: #50fa7b; }

Bucle @while:

// utilidades/_grid.scss $contador: 1; @while $contador <= 3 { .columna-#{$contador} { width: (100% / $contador); } $contador: $contador + 1; }
✅ Caso de uso real: Los bucles son perfectos para generar clases de utilidad (Bootstrap, Tailwind), sistemas de espaciado y breakpoints responsive.

⚡ Condicionales en SASS

Los condicionales (@if, @else if, @else) permiten aplicar estilos de manera condicional basándose en variables.

Ejemplo Visual - Tema Claro/Oscuro

Tema Claro

Fondo blanco
Texto oscuro

Tema Oscuro

Fondo oscuro
Texto claro

// _variables.scss $tema: dark; $tamaño-pantalla: mobile;
// base/_layout.scss @import '../_variables'; @if $tema == dark { body { background: #333; color: #fff; } } @else { body { background: white; color: #333; } } @if $tamaño-pantalla == mobile { .container { width: 100%; } } @else if $tamaño-pantalla == tablet { .container { width: 768px; } } @else { .container { width: 1200px; } }

Condicionales en Mixins:

// _mixins.scss @mixin boton($tipo) { padding: 12px 25px; border-radius: 5px; border: none; cursor: pointer; transition: all 0.3s; @if $tipo == primary { background: #667eea; color: white; &:hover { background: #5568d3; } } @else if $tipo == outline { background: transparent; border: 2px solid #667eea; color: #667eea; &:hover { background: #667eea; color: white; } } @else if $tipo == disabled { background: #ccc; color: #999; cursor: not-allowed; } }
// componentes/_botones.scss @import '../_mixins'; .btn-primary { @include boton(primary); } .btn-outline { @include boton(outline); } .btn-disabled { @include boton(disabled); }

Operadores en condicionales:

  • == - Igualdad
  • != - Desigualdad
  • <, >, <=, >= - Comparación numérica
  • and - Y lógico
  • or - O lógico
  • not - Negación

📁 Modularización e Integración en Proyectos

La modularización permite dividir tu código SASS en archivos más pequeños y manejables, mejorando la organización y mantenibilidad del proyecto.

Estructura recomendada de carpetas:

proyecto/ │ ├── scss/ │ ├── main.scss # Archivo principal │ ├── _variables.scss # Variables globales │ ├── _mixins.scss # Mixins reutilizables │ ├── _funciones.scss # Funciones personalizadas │ ├── _reset.scss # Reset/Normalize │ │ │ ├── base/ │ │ ├── _tipografia.scss │ │ ├── _colores.scss │ │ └── _layout.scss │ │ │ ├── componentes/ │ │ ├── _botones.scss │ │ ├── _tarjetas.scss │ │ ├── _header.scss │ │ └── _footer.scss │ │ │ └── utilidades/ │ ├── _espaciado.scss │ └── _responsive.scss │ ├── css/ │ └── main.css # CSS compilado │ └── index.html

Archivo principal (main.scss):

// main.scss // 1. Configuración global @import 'variables'; @import 'funciones'; @import 'mixins'; // 2. Estilos base @import 'reset'; @import 'base/tipografia'; @import 'base/colores'; @import 'base/layout'; // 3. Componentes @import 'componentes/botones'; @import 'componentes/tarjetas'; @import 'componentes/header'; @import 'componentes/footer'; // 4. Utilidades @import 'utilidades/espaciado'; @import 'utilidades/responsive';

Ejemplo: _variables.scss

// _variables.scss // Colores $color-primario: #667eea; $color-secundario: #764ba2; $color-exito: #50fa7b; $color-error: #ff6b6b; $color-fondo: #f5f5f5; $color-texto: #333; // Tipografía $font-principal: 'Segoe UI', sans-serif; $font-secundaria: 'Georgia', serif; $font-size-base: 16px; $font-size-sm: 14px; $font-size-lg: 18px; // Espaciado $espaciado-xs: 5px; $espaciado-sm: 10px; $espaciado-md: 20px; $espaciado-lg: 30px; // Breakpoints $mobile: 480px; $tablet: 768px; $desktop: 1024px;

Ejemplo: _mixins.scss

// _mixins.scss // Responsive @mixin mobile { @media (max-width: $mobile) { @content; } } @mixin tablet { @media (max-width: $tablet) { @content; } } // Utilidades comunes @mixin flex-center { display: flex; justify-content: center; align-items: center; } @mixin transition($prop: all, $duracion: 0.3s) { transition: $prop $duracion ease; }

Ejemplo: componentes/_botones.scss

// componentes/_botones.scss @import '../_variables'; @import '../_mixins'; // Estilos base para botones %boton-base { padding: $espaciado-sm $espaciado-md; border: none; border-radius: 5px; cursor: pointer; font-weight: 600; @include transition; } .btn { @extend %boton-base; background: $color-primario; color: white; &:hover { background: darken($color-primario, 10%); transform: translateY(-2px); } @include tablet { padding: $espaciado-xs $espaciado-sm; } }

Cómo usar en HTML:

<head> <link rel="stylesheet" href="css/main.css"> </head> <body> <button class="btn"> Botón Primario </button> </body>
💡 Ventajas de la modularización:
  • Código más organizado y fácil de mantener
  • Facilita el trabajo en equipo
  • Reutilización de código
  • Reducción del CSS final compilado
  • Mejor rendimiento del proyecto
